Kalkulator Splitter Rasio

Aplikasi kalkulator rumus splitter ratio untuk menentukan persentase rasio ODC dan menghitung estimasi redaman ODP pada jaringan fiber optik (FTTH).

Aplikasi Kalkulator Rasio

*Gunakan tanda titik (.) untuk angka koma/desimal

Hasil Perhitungan Output

Out ODC Persen Kecil (Branch)
0 dBm

Diteruskan ke ODP Lintas ini

Out ODC Persen Besar (Trunk)
0 dBm

Diteruskan ke ODC berikutnya

Output Redaman Port ODP (1:8)
0 dBm

Estimasi daya sinyal yang diterima di port pelanggan (ONT/Splicing)

Catatan Tambahan: Hasil perhitungan di atas merupakan nilai rasio ideal teoretis. Dalam praktik lapangan, Anda perlu menambahkan faktor total attenuation losses (~0.2 - 0.5 dB per titik sambungan/splicing, konektor SC/UPC/APC, adapter/barel, fastconnector, serta bend radius/tekukan kabel).
