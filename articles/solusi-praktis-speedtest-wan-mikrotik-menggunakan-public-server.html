Solusi Praktis Speedtest WAN MikroTik Menggunakan Public Server

Al Ikhsan Nahdillah Muis Malik / 26 Agustus 2026
Mikrotik Speedtest
Bagikan:

Pernahkah Anda perlu mengecek kecepatan koneksi internet pada perangkat MikroTik yang lokasinya jauh dari Anda? Biasanya, kita berpikir harus datang langsung ke lokasi atau terhubung ke jaringan lokalnya untuk melakukan speedtest via perangkat endpoint user. Padahal, MikroTik sudah menyediakan fitur bawaan yang memungkinkan kita melakukan uji kecepatan secara remote tanpa perlu hadir langsung ke lokasi.


Caranya adalah dengan memanfaatkan fitur Speedtest Mikrotik. Untuk menggunakan fitur ini, kita membutuhkan BTest Server Public atau Bandwidth Test Server Public .Server-server publik ini disediakan dan dibagikan secara gratis oleh komunitas ISP untuk membantu para pengelola jaringan. Salah satu server yang bisa Anda gunakan adalah milik Alagas Network dengan detail rincian akses sebagai berikut:


  1. Address: mikrotik.speedtest.alagas.net
  2. User: speedtest
  3. Password: MikroTikSG


Untuk mulai melakukan pengujian, Anda bisa mengikuti langkah-langkah praktis berikut:

  1. Buka menu Terminal di WinBox/MikroTik Anda, lalu jalankan perintah

ping mikrotik.speedtest.alagas.net count=4

untuk mendapatkan IP Host BTest server tersebut.


  1. Buka menu Tools > Speed Test.
  2. Masukkan IP Host yang Anda dapatkan dari hasil ping tadi ke kolom Address.
  3. Masukkan User dan Password sesuai parameter di atas.
  4. Klik Start untuk memulai pengujian, tunggu hingga status berubah menjadi Done dan perhatikan hasil throughput yang muncul.


Contoh untuk hasil speedtest saya Kecepatan unduh maksimal yang berhasil dicapai menggunakan protokol TCP adalah 172 Mbps dan kecepatan unggah maksimal yang berhasil dicapai menggunakan protokol TCP adalah 58.1 Mbps.


Hal Penting Yang Perlu Di Perhatikan Saat Menggunakan Server Publik

  1. Karena server-server BTest di internet dikelola secara mandiri oleh sukarelawan, pastikan untuk selalu menjaga etika penggunaan. Batasi pengujian maksimal 10–30 detik per sesi agar server tidak kelebihan beban dan IP Anda tidak terdeteksi sebagai serangan DDoS.
  2. Perlu diingat juga bahwa server publik bisa mengalami downtime atau ditutup sewaktu-waktu, seperti server legendaris milik TomjNorthIdaho (207.32.195.2) yang kini sudah offline permanen akibat overload.
  3. Gunakan secara bijak agar fasilitas publik ini bisa terus dinikmati oleh komunitas.
